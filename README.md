# ส่องลอตเตอรี่

เว็บตรวจเลขสลากกินแบ่งรัฐบาลกับผลรางวัลย้อนหลังตั้งแต่ปี 2549 พร้อมดูเลขเฉียด เลขสลับตำแหน่ง และสถิติย้อนหลัง
ผลรางวัลงวดใหม่อัปเดตเองด้วย GitHub Actions แล้วเผยแพร่ผ่าน GitHub Pages

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บที่ GitHub Pages เปิด (สร้างอัตโนมัติ ไม่ต้องแก้เอง) |
| `data/draws.json` | ผลรางวัลทุกงวด บรรทัดละ 1 งวด |
| `src/template.html`, `src/engine.js` | ต้นฉบับหน้าเว็บและตรรกะการตรวจ แก้ที่นี่แล้วระบบจะสร้าง `index.html` ใหม่ให้ |
| `scripts/update_draws.py` | ดึงผลงวดใหม่ ตรวจว่าครบทุกรางวัลก่อนบันทึก |
| `scripts/build.py` | รวมข้อมูลกับต้นฉบับเป็น `index.html` |
| `.github/workflows/update.yml` | ตั้งเวลารันทุกวัน 17:30 และ 20:30 น. (เวลาไทย) |

## วิธีติดตั้ง

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`)
2. ไปที่ **Settings → Pages** เลือก Source เป็น **Deploy from a branch** เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
3. ไปที่ **Settings → Actions → General** หัวข้อ *Workflow permissions* เลือก **Read and write permissions** แล้วกด Save
4. ไปที่แท็บ **Actions** กด workflow *Update lottery results* → **Run workflow** เพื่อทดสอบครั้งแรก
5. รอ 1–2 นาที เว็บจะเปิดได้ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## การทำงานอัตโนมัติ

- ทุกวัน ระบบจะไล่ตรวจทุกวันที่หลังงวดล่าสุดที่มีอยู่ จึงรองรับงวดที่เลื่อนวัน (2 พ.ค., 17 ม.ค., 30 ธ.ค. หรือวันหยุดพิเศษ) ได้เอง
- ดึงจากหน้า `news.sanook.com/lotto/check/<วันเดือนปี พ.ศ.>/` มีตัวอ่าน 2 แบบสำรองกัน และบันทึกเฉพาะเมื่อครบทุกรางวัล
  (รางวัลที่ 1, 2×5, 3×10, 4×50, 5×100, หน้า 3 ตัว ×2, ท้าย 3 ตัว ×2, ท้าย 2 ตัว ×1) ถ้าตอน 17:30 ผลยังไม่ครบ รอบ 20:30 หรือวันถัดไปจะลองใหม่
- มีงวดใหม่เมื่อไร ระบบจะ commit ข้อมูลและหน้าเว็บใหม่ แล้ว GitHub Pages จะอัปเดตภายในไม่กี่นาที
- ถ้าไม่มีงวดใหม่เกิน 20 วัน (เช่น เว็บต้นทางเปลี่ยนหน้าตา) จะขึ้นคำเตือนในหน้า Actions

## ดึงงวดที่ต้องการเอง

แท็บ **Actions → Update lottery results → Run workflow** แล้วใส่วันที่แบบ ค.ศ. เช่น `2026-11-01`

หรือแก้ `data/draws.json` เองโดยเพิ่มบรรทัดรูปแบบเดียวกับบรรทัดอื่น แล้ว commit ระบบจะสร้างหน้าเว็บใหม่ให้ในรอบถัดไป
(หรือรัน `python scripts/build.py` ในเครื่องแล้ว commit `index.html` ด้วย)

## หมายเหตุ

- GitHub จะหยุดงานตั้งเวลาอัตโนมัติถ้า repository ไม่มีความเคลื่อนไหวเลย 60 วัน ปกติระบบ commit ทุกงวดอยู่แล้วจึงไม่น่าเกิด
  ถ้าเกิดขึ้น ให้กดเปิดใหม่ในแท็บ Actions
- ผลรางวัลโปรดตรวจกับประกาศของสำนักงานสลากกินแบ่งรัฐบาลอีกครั้งก่อนขึ้นเงิน
